# SIH Requirement Mapping

| Requirement | BidGuard implementation |
|---|---|
| Tender requirement identification | Requirement extraction endpoint + normalized requirement records |
| Multi-document evidence | File upload and document metadata |
| Compliance verification | Weighted rule engine |
| Risk analysis | Explainable risk score and drivers |
| Government verification | Adapter endpoint with clearly marked demo registry |
| Human-in-the-loop | Officer final decision |
| Transparency | Requirement-level explanations |
| Auditability | Audit event timeline |
| Reporting | PDF assessment report |
| Role based access | Officer/Admin/Auditor login and decision authorization |
| Local deployment | FastAPI + SQLite + React/Vite |

The project does not claim unauthorized direct access to restricted government databases.
