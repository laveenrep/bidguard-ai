# 7-minute SIH Demo Script

## 0:00 — Login
Show Officer role and dashboard.

## 0:45 — Tender intelligence
Open a tender. Show the normalized requirements and run extraction.

## 1:45 — Bidder evidence
Open a bidder. Show identifiers and upload a sample TXT/CSV/PDF evidence file.

## 2:30 — Compliance
Run the assessment. Explain PASS/FAIL and weights.

## 3:45 — Government verification
Verify GST/PAN/Udyam. Explain that the UI is adapter-ready and the demo registry is used because production government access requires authorization.

## 4:45 — Risk
Run risk analysis and show drivers.

## 5:30 — Human decision
Return to Compliance. Select APPROVE/REJECT/REVIEW and enter a reason.

## 6:15 — Report and audit
Generate PDF. Open Audit Trail and show login, upload, verification, compliance and decision events.
