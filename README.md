# BidGuard AI

AI-Powered Tender & Bid Compliance Monitoring System

## Overview

BidGuard AI is a web-based system designed to help organize and analyze government tender and bidder information.

The system provides a centralized platform for tender management, bidder information, document/evidence processing, compliance checking, and risk analysis.

## Problem

Government tender and bid evaluation processes involve large amounts of documents and compliance requirements.

BidGuard AI aims to simplify this process by organizing tender information and assisting with compliance and risk analysis.

## Key Features

- Tender management dashboard
- Bidder management
- Document and evidence processing
- Compliance checking
- Risk analysis
- Government verification API architecture
- JWT-based authentication
- REST API backend
- Interactive web dashboard
